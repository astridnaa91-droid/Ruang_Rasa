# Ruang Rasa

Ruang Rasa adalah platform aplikasi manajemen restoran berbasis web yang dibangun menggunakan framework Laravel. Aplikasi ini dikembangkan untuk mempermudah pengelolaan operasional restoran, mulai dari manajemen menu hingga sistem pemesanan.

## 2. Deskripsi & Fitur Aplikasi

Aplikasi ini membagi sistem menjadi beberapa akses utama untuk mendukung operasional restoran:

- **Fitur Admin**: Mengelola data menu, memantau pesanan, dan melakukan operasi CRUD (Create, Read, Update, Delete) pada data sistem.
- **Fitur User**: Melihat daftar menu, melakukan pemesanan, dan mengelola keranjang belanja.
- **RESTful API**: Aplikasi ini dilengkapi dengan endpoint API yang terdokumentasi untuk mendukung komunikasi data yang efisien.

## 3. Instalasi

Untuk menjalankan aplikasi ini di komputer lokal:

1. Clone repository: `git clone https://github.com/astridnaaa/Ruang_Rasa.git`
2. Masuk ke direktori: `cd Ruang_Rasa`
3. Install dependensi: `composer install`
4. Copy file environment: `cp .env.example .env`
5. Jalankan migrasi database: `php artisan migrate`
6. Jalankan server: `php artisan serve`
